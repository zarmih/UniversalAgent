# Безопасность UniversalAgent

UniversalAgent спроектирован с упором на локальную безопасность и изоляцию.

1. **Отсутствие sudo:** Оркестратор и воркеры не требуют прав суперпользователя.
2. **Изоляция:** Задачи выполняются внутри `tmux` сессий, предотвращая прямой доступ к корневому окружению родительского процесса.
3. **Approval Policy:** Действия разделены на "безопасные" (read-only) и "опасные" (write/submit). Опасные действия блокируются и ожидают `/approve` от пользователя.
4. **Хранение секретов:** Секретные ключи не пишутся в публичные логи и не передаются в неконтролируемые воркеры. Воркер получает только минимально необходимые переменные окружения через локальный `.env`.
5. **Ограничение сетевого доступа:** При необходимости сетевой доступ изолируется на уровне воркера, чтобы исключить утечки (например, блокировка телеметрии).
