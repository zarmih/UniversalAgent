# Конфигурация UniversalAgent

Конфигурация оркестратора производится через переменные окружения или файл `.env` в корневой директории.

- `PORT`: Порт для FastAPI (по умолчанию `8765`).
- `HOST`: Хост для привязки API (по умолчанию `127.0.0.1`).
- `SQLITE_DB_PATH`: Путь к базе данных (по умолчанию `data/universal_agent.sqlite`).
- `WORKSPACES_DIR`: Директория для изоляции задач файловой системы (по умолчанию `workspaces/`).
- `RUNTIME_LOGS_DIR`: Директория для логов выполнения воркеров (по умолчанию `runtime/`).

Воркеры также могут использовать отдельный конфигурационный файл (например, `agy-worker.env`) для инъекции прокси или специфичных локальных настроек без публикации их в основном репозитории.
